# 🎮 GAMEZONE - Catálogo de Videojuegos

## Descripción del proyecto

GameZone es un sitio web desarrollado como proyecto final de la materia de Programación Web.

Su propósito es permitir el registro, administración y consulta de videojuegos mediante un catálogo interactivo.

El sistema permite agregar videojuegos, visualizar sus detalles, editar su información y eliminarlos. También cuenta con un buscador por nombre y un filtro por género.

## Funcionalidades

- Registrar videojuegos.
- Consultar videojuegos registrados.
- Editar información de videojuegos.
- Eliminar videojuegos.
- Buscar videojuegos por nombre.
- Filtrar videojuegos por género.
- Visualizar detalles de cada videojuego.
- Mostrar información almacenada en una base de datos SQLite.

## Tecnologías utilizadas

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- PHP
- SQLite
- Git y GitHub
- WampServer 64

## Requisitos para ejecutar el proyecto

- Tener instalado WampServer 64.
- Contar con PHP habilitado.
- Tener disponible SQLite para PHP.
- Utilizar un navegador web.

## Instrucciones de instalación y ejecución

1. Descargar o clonar el repositorio de GitHub.
2. Colocar la carpeta del proyecto dentro de la carpeta `www` de WampServer.
3. Iniciar los servicios de WampServer.
4. Verificar que Apache y PHP estén funcionando.
5. Abrir el navegador.
6. Escribir la siguiente dirección:

   http://localhost/nombre-de-tu-carpeta/

7. El sistema mostrará la página principal de GameZone.

## Base de datos

El proyecto utiliza SQLite para almacenar la información de los videojuegos.

La base de datos permite guardar y consultar los registros para mantener actualizado el catálogo.
